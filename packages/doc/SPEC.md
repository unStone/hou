# 《厚》统一阅读格式 · 第 1 版

所有读物（EPUB、PDF、网页、微信公众号、X、粘贴的正文）导入时都转换为这一种格式。阅读器、高亮、批注、原文定位、知识点提取只处理这一种格式。类型定义见 [`src/types.ts`](src/types.ts)。

## 文档

一份读物保存为一个目录：

```
<读物目录>/
  doc.json      文档本身（本规范）
  original.*    原始文件或网页快照，用于"查看原版"和重新转换
  assets/       图片等本地资源
```

`doc.json` 的顶层结构：

| 字段 | 说明 |
|---|---|
| `format` | 固定为 `hou-doc` |
| `version` | 格式版本，当前为 `1` |
| `meta` | 元信息，见下表 |
| `chapters` | 章节列表，至少一个 |
| `assets` | 本地资源列表 |

`meta`：

| 字段 | 说明 |
|---|---|
| `title` | 标题，必填 |
| `author` | 作者，可选 |
| `kind` | `book` 或 `article`，决定占用哪个在读名额 |
| `language` | 语言，可选，例如 `zh-CN` |
| `source` | `{ type, url?, file? }`，`type` 为 `epub`、`pdf`、`web`、`wechat`、`x`、`text` 之一 |
| `importedAt` | 导入时间，ISO 8601 |
| `converter` | `{ name, version }`，产出文档的转换器，用于排查转换问题 |

## 章节与内容块

章节：`{ id, title, blocks }`。阅读器按章节显示，"标记读完"和知识点提取都以章节为单位。

内容块是扁平的列表，不嵌套。引用里的多个段落转换为多个 `quote` 块。

| 类型 | 字段 | 块文本（定位用） |
|---|---|---|
| `heading` | `level`（1–6）、`content` | 行内文本 |
| `paragraph` | `content` | 行内文本 |
| `quote` | `content` | 行内文本 |
| `list` | `ordered`、`items`（每项为行内内容） | 各项以换行连接 |
| `code` | `text`、`language?` | `text` |
| `image` | `asset`（资源编号）、`alt`、`caption?` | 有说明时为说明，否则为 `alt` |
| `table` | `header`（首行是否为表头）、`rows`（行 → 单元格 → 行内内容） | 单元格以制表符、行以换行连接 |
| `math` | `tex`（LaTeX） | `tex` |
| `divider` | 无 | 空 |

章节标题不重复出现在内容块中。章节内的小标题保留原文的级别。

## 行内内容

| 类型 | 字段 |
|---|---|
| `text` | `text`；`marks?` 为 `bold`、`italic`、`code` 的组合；`href?` 为链接地址 |
| `math` | `tex` |

换行用文本中的 `\n` 表示。中文之间不保留 HTML 源码换行产生的空格。

## 编号

- 章节编号 `c1`、`c2`…，块编号 `b1`、`b2`…，按出现顺序分配，在整份文档内唯一。
- 编号由 `buildDocument` 统一分配，转换器不自行编号。
- 文档导入后不再修改。重新转换会生成新版本，编号可能变化，旧版本上的原文位置用下面的方式迁移。

## 原文位置

高亮、批注、知识点出处统一记录为：

```json
{ "blockId": "b12", "start": 6, "end": 15, "quote": "而是让重点被看见。" }
```

- `start`、`end` 是块文本中的字符位置（UTF-16，与 JavaScript 字符串一致），范围为 `[start, end)`。
- `quote` 保存当时的原文片段。
- 找回位置时，先核对块编号和范围；对不上时，在全文中查找与 `quote` 完全一致的第一处。仍找不到时提示用户原文已变化。

## 资源

`{ id, path, mediaType, sourceUrl? }`。`path` 是读物目录内的相对路径，不能以 `/` 开头，也不能包含 `..`。图片在导入时全部下载到本地，文档内不引用外部地址。

## 版本演进

- 新增可选字段或新的块类型时，`version` 加一，并提供从旧版本升级的函数。
- 阅读器遇到不认识的块类型时，显示其块文本，不报错。
